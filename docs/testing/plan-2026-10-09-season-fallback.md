# QA-07: シーズン切り替わり時の採用統計フォールバック

## 目的

シーズン切り替わり後、現シーズンの技・特性・持ち物・性格・能力配分が未掲載または部分的な場合に、提供元の一覧で確認できる直前シーズンの統計を使う。現シーズンが十分そろっていれば現シーズンを優先する。

## 実装方針

- `/api` の `defaultSeason` と `seasons` を基準に現シーズンと直前の一つを決める。季節や日付を固定せず、一覧にないシーズンや直前より古い統計を許可しない。
- 現シーズンの個別データを先に取得する。5カテゴリがそろえば前シーズンを追加取得しない。不足または取得失敗時だけ前シーズンを確認し、カテゴリ数が多い一つのスナップショットを採用する。同数は現シーズンを優先し、カテゴリをシーズン間で混ぜない。
- 既存の技・特性・持ち物・フォームの合法性フィルタは維持する。計算カタログは生成物のM6を保ち、カタログ未登録候補を除外する。
- キャッシュをシーズン別v2へ切り替える。有効な一致シーズンv2を優先し、存在しない場合だけ一致する旧v1を移行する。日次更新と手動再試行は現シーズンを再確認する。
- 表示は出典シーズンと欠落カテゴリを日本語で知らせる。メガ進化前参照、保存済み型、手動編集は既存経路を維持する。

## 受け入れと検証

- 現シーズン完全時は前シーズンへの追加通信なし。
- 空・404・部分取得時は一つ前だけを確認し、応答シーズン不一致と二つ以上前は拒否する。
- 両方が部分的ならカテゴリ数の多い一方を表示し、前シーズンがなければ現シーズンの部分データを保持する。
- 日次再確認と手動再試行で現シーズンのデータへ復帰する。既存の有効なv2キャッシュは旧v1で上書きしない。
- 自動初期型、持ち物並び、仮定、予測へ同じシーズン確認を通し、保存済み型と手動編集を維持する。
- 自動テスト、型チェック、整形チェック、ビルドを実行する。Browser Useでローカル画面を確認し、出典シーズンと表示状態を確かめる。
