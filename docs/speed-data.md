# すばやさ比較のデータと範囲

## 対象データ

2026-09-18に取得したPokémon ShowdownのChampions用データを使用する。
`formats-data.ts`で`isNonstandard`がなく、`tier`が`Illegal`または`Unreleased`ではない行を全て収録する。個別の形式行がない性別・戦闘フォームは基底フォームの形式情報を継承する。358フォーム・231図鑑番号を含む。
通常・リージョン・メガシンカ・戦闘中のフォームを区別する。同じ図鑑番号でも別の比較対象となる。`isCosmeticForme`の外見差分は基底フォームにまとめ、独自の種族値定義があるフォームのみを個別表示する。

- 対象: <https://github.com/smogon/pokemon-showdown/blob/master/data/mods/champions/formats-data.ts>
- 種族値: <https://github.com/smogon/pokemon-showdown/blob/master/data/pokedex.ts>
- 日本語名: <https://github.com/PokeAPI/pokeapi/blob/master/data/v2/csv/pokemon_species_names.csv>

これは公式の利用可能一覧との照合結果ではない。開催中のランクバトルの追加制限・最新配信状況を保証しない。画面のデータ説明に出典・取得日・制限を明記する。
使用率APIとは独立した静的データで、自動更新しない。

## 再生成

```sh
node scripts/generate-speed-roster.mjs
npm test
npm run build
```

通信が制限されている場合は、`formats.ts`、`pokedex.ts`、`names.csv`を同じディレクトリに取得し、そのディレクトリを引数に渡す。
TypeScriptのASTからリテラルだけを読み、ダウンロードしたコードは実行しない。生成JSONに取得日・ソースURL・SHA-256を記録する。
更新でフォーム数が変わった場合は元データと除外条件を確認した上で、スナップショットの件数テストを更新する。
未知のフォーム名は生成時に一覧表示するので、翻訳を確認する。

## 計算

Pokémon Showdownの[Champions statModify](https://github.com/smogon/pokemon-showdown/blob/master/data/mods/champions/scripts.ts)とSmogon Damage Calculatorの[calcStatChampions](https://github.com/smogon/damage-calc/blob/master/calc/src/stats.ts)を参照。

1. `(種族値 + SP + 20) × 性格補正`を切り捨てる（性格補正は110/100・100/100・90/100）。SPは整数0〜32。
2. 能力ランクを適用して切り捨てる。正のランクは`(2 + ランク) / 2`、負のランクは`2 / (2 - ランク)`。
3. 特性とスカーフの倍率を合成して適用する。Pokémon Showdownの`Battle.modify`と同じ4096固定小数点の丸め（0.5は切り捨て、それを超えた端数は切り上げ）を用いる。スカーフ単体では整数値の1.5倍の切り捨てと同じになる。メガフォームやかるわざ発動中にはスカーフを適用できない。

レベル・個体値は入力しない。おいかぜ、まひの減速、トリックルーム、技の優先度やその他の持ち物は対象外。完全な行動順の判定ではない。

特性は[Showdownの特性定義](https://github.com/smogon/pokemon-showdown/blob/master/data/abilities.ts)と[Championsの上書き](https://github.com/smogon/pokemon-showdown/blob/master/data/mods/champions/abilities.ts)を参照し、倍率を計算する。すいすい・ようりょくそ・すなかき・ゆきかき・かるわざ・サーフテールは2倍、はやあしは1.5倍、スロースタートは0.5倍。選択肢には収録対象が所持可能な特性だけを表示する。
フォームごとの特性リストは種族値と同じ`pokedex.ts`から生成する。選んだ特性を持たないフォームには適用しない。複数の特性が同時に発動する想定は扱わない。
天候・状態異常等の条件は自動判定せず、選択した特性が発動済みかつ無効化されていない想定。かるわざは持ち物消失済みの想定でありスカーフとは併用不可。はやあしは状態異常時の倍率だけを適用し、まひの減速を重ねない。相手のランク上昇は下記の習得技・特性判定から列挙する。自分のランクは手動で指定する。

初期表示は最速・準速・無振り・最遅・最速スカーフを混在させ、同じポケモンも配分・ランクごとに別の行で比較する。「配分で絞り込み」で1配分に限定でき、「すべて」で戻せる。全ポイント配分の総当たりではなく代表的な5配分が対象。メガシンカ・かるわざ発動中のスカーフの型は除外する。最速は上昇補正32 SP、準速は補正なし32 SP、無振りは補正なし0 SP、最遅は下降補正0 SP。相手のランクは初期表示で0・＋1・＋2を混在させ、ランクボタンで絞り込める。＋1・＋2は下記の上昇手段がある相手に限る。自分のランク・特性と相手の条件は独立している。
選択フォームは相手一覧から除き、編集した条件で基準の1行として挿入する。順位は`自分より速い型の数 + 1`とし、同速は同順位。順位・分布・近傍の対象は配分・ランクの絞り込みに連動し、件数の単位はフォーム数ではなく型の数。近傍と各行に配分名を表示する。
検索・表示範囲は表のみを絞り込み、上部の分布・順位・近傍の計算母集団は変えない。図鑑検索は日本語ひらがな・カタカナ・英語名・図鑑番号に対応。
初回表示はページと表の両方をスクロールし、選択中の行を中央に表示する。条件変更やサイズ変更時は表のスクロール位置のみを調整して、操作中のページ位置を維持する。

## 自分でランクを上げられる相手の判定

`src/speed-boosts.ts` の効果ルールを、`battle-catalog.json` のフォーム別習得技と `speed-roster.json` の特性に照合する。効果は [Showdown の技定義](https://github.com/smogon/pokemon-showdown/blob/master/data/moves.ts)・[特性定義](https://github.com/smogon/pokemon-showdown/blob/master/data/abilities.ts)に基づく。収録技や特性が増えた際は効果ルールも確認する。

- ランク0を基点に、単一の技／特性で正確に＋1または＋2へ到達する状態のみ。りゅうのまい等の＋1は1回／2回、からをやぶる等の＋2は1回。＋2の手段から＋1を作らない。
- こうそくいどう、ロックカット、ギアチェンジ、ちょうのまい、ニトロチャージ、くさわけ、アクアステップ、こうそくスピン、スケイルショット、オーラぐるま、ソウルビート等を含む。はいすいのじん・きずなへんげは通常繰り返せないため1回のみ。
- 特性は、かそく、くだけるよろい、ふくつのこころ、びびり、でんきエンジン、ムラっけ、きずなへんげ。被弾・ひるみ・撃破等の条件を行に記載する。げんしのちから・つぼをつく・ムラっけは確率的な効果が発動した場合に限る。発動確率は順位の重みには使わない。
- あまのじゃく固定フォームでは正の自己強化を除外し、ちからずくでは攻撃技の追加効果による上昇を除外する。アームハンマー・アイスハンマー・非ゴーストののろいは、あまのじゃくと併用できる場合のみ上昇手段になる。すいすい等の倍率特性を適用する行では、別のランク上昇特性を同時に使わない。
- うなぎのぼりは対象のメガシビルドンの代表配分ではすばやさが最高の能力にならず、能力操作を加えない本比較には含めない。じょうききかんの＋6は今回の対象ランク外。
- 相手から付与される上昇、コピー・特性変更、複数手段の組合せ、途中でランクを下げて調整する経路は列挙しない。技命中・必要HP・残りPP・発動条件は成立済みの想定。ターンごとの実行可能性を解くシミュレーターではない。

同じ配分・ランクに複数の上昇手段がある場合も行は1件とする。比較条件には根拠の一例を表示し、残りは展開して確認できる。順位・分布・近い相手もこの型一覧を母集団とする。
