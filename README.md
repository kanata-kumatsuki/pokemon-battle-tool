# BATTLE NOTE

ポケモンチャンピオンズのシングル対戦支援ツールです。UIプレビューから、ダメージ計算・採用データ取得・行動候補の評価が動作するベータ版へ移行しました。非公式のツールです。

初回起動では攻撃側・受け側を未選択で表示し、ダメージ計算、すばやさ比較、パーティ編成、能力ランクの順に使う場所を案内します。ガイドはスキップでき、ヘッダーの「使い方」からいつでも再開できます。ガイドの既読状態はパーティ・履歴とは別のブラウザ保存領域に記録します。以前から保存データがある利用者には自動表示しません。

## 起動と検証

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run format:check
npm run build
```

開発サーバーは `http://127.0.0.1:5173`。ビルド成果物は `dist/` です。公開デプロイはまだ行っていません。
今回のQA進捗・実行結果は [QA-06 統合検証レポート](docs/testing/qa-06-integration.md) を参照してください。

## 実装した機能

- 青・紫のスタジアムを基調としたトップページ。各ツールと使い方へ移動でき、ロゴまたは「ホーム」で戻れます

- 358フォームの検索・選択。APIで確認した現シーズンまたは直前シーズンの採用統計があれば、合法な採用上位設定を初期型に反映し、特性・持ち物・性格・配分・技を編集
- `@smogon/calc@0.12.0` のChampionsモードによるダメージ幅・HP割合・一撃撃破率、同じ条件を反復した撃破回数の目安
- 性格、能力ポイント、持ち物、特性、残りHP、状態異常、能力ランク、天候、フィールド、壁、おいかぜ、まもる、重力、急所、連続技の回数
- 攻守の入れ替え。行動順は技の優先度・すばやさ・トリックルーム等から判定
- 対応メガストーンの所持に連動して、画像・種族値・タイプ・特性・ダメージ・すばやさをメガシンカ後に切替。外すと通常状態へ復帰
- メガフォームを直接選んだ場合は、一意に対応する通常フォームの採用統計を表示・参照し、メガ後に合法な候補だけ初期型へ適用。統計元の通常フォームも画面に明記
- 全対象と比べる専用すばやさページ。順位、分布、近い相手、ランク補正・特性発動時の比較、小型アイコン・タイプ色
- 3パーティ×6枠の編集・端末保存。パーティごとに未保存状態を表示し、変更を保存して書き出せる。攻守それぞれ最大6件の異なる型を履歴に保持
- 初回利用時は採用順位からスタンダードパーティを6体選出。メガフォームとメガストーンを持つ通常フォームを合わせて最大2体とし、3体目以降は順位を下げて補充
- 攻撃側・受け側は起動時に未選択で開始。両方を選ぶまではダメージ結果、対面速度、予測を表示せず、すばやさ専用ページではポケモンを直接選択可能
- 対戦条件の入力に応じて結果を自動更新。「結果を見る」は結果への移動のみで、攻守の型は別操作で履歴へ保存
- 保存済みパーティ・履歴のJSON書き出し／検証付き読み込み
- 相手の見せ合い6枠を名前・図鑑番号で検索。重複を防ぎ、選出／ひんし状態と判明した特性・持ち物・性格・配分・技を入力
- 採用上位、速度、物理耐久、スカーフを仮定した型の比較。判明項目は固定
- 採用率・ダメージ・行動順を使い、技と交代を合わせて最大3候補を表示。根拠と仮定を明示し、不足時に候補を水増ししない
- Pokémon Champions Battle Data APIから一覧と選択したポケモンの詳細を取得。現シーズンの統計が不足するときは直前シーズンを表示し、出典シーズンと不足項目を明記。日本時間の当日初回利用時に更新し、失敗時は前回データを保持。手動再試行、データ日付と取得成功日時を表示

## 対応範囲

実装と制約の詳細は [docs/implementation.md](docs/implementation.md) を参照してください。バトル画面では結果カードが画面外にある間、ダメージ割合・撃破の目安・規定回数内のKO率を画面下部に固定表示します。反復目安は同技・同条件を最大10回使う簡易計算で、完全な対戦シミュレーターではありません。相手のオボンのみ・オレンのみ・たべのこしによる回復を反映し、「回復なし」に切り替えられます。命中失敗やその他のターン終了時効果は含まず、未対応条件は画面に表示します。新シーズンは互換性確認後に対応シーズンを更新します。

対象はShowdownのChampionsスナップショットです。イベント固有の参加制限まで保証する参加可否判定ではありません。統計の対象シーズンはAPI一覧で確認した現シーズンと直前シーズンです。計算カタログは生成済みのM6を維持し、カタログ未登録の候補を除外します。専用すばやさページは速度帯比較用で、場の詳細を含む対面の行動順はダメージ画面で確認します。

保存キーは既存の `battle-note-ui-v1` を継続しています。未変更のパーティは保存値を保ち、編集したパーティは保存状態を表示します。「保存済みを書き出す」は保存済みデータだけを含み、「保存して書き出す」は編集した全パーティを検証し、端末保存に成功してから書き出します。端末への保存に失敗した場合は編集を維持し、未保存のパーティ編集を含むバックアップを選べます。JSONバックアップにはパーティと攻守の型履歴が含まれ、対戦中のHP・天候・判明情報や採用データキャッシュは含みません。履歴へ保存するのは攻守の型で、現在HPや天候などの対戦条件は含みません。判明情報は対戦中、相手を切り替えても保持し、リセットで消去します。別端末へはJSONで移行します。

保存データがない初回だけ、採用順位からスタンダードの6体を選びます。順位のない候補やカタログ未登録の候補は飛ばし、メガフォームとメガストーンを持つ型を合わせて最大2体にします。順位取得に失敗した場合は初期サンプルを保ち、保存せず、次回起動時に再試行します。既存の保存データがある場合や、選出中にパーティを操作した場合は自動選出を適用しません。

## データの更新

生成物は手編集せず、以下のスクリプトを使います。公開ソースのリテラルをASTで読み取り、リモートコードは実行しません。

```sh
node scripts/generate-speed-roster.mjs
node scripts/generate-speed-icons.mjs
node scripts/generate-battle-catalog.mjs
node scripts/generate-artwork.mjs
```

種族データを更新したら、対戦カタログと全身イラストも更新してテストしてください。画像の再生成方法は [docs/artwork-sources.md](docs/artwork-sources.md) を参照してください。対戦カタログは出典・取得日時・ソースのSHA-256・計算ライブラリのバージョンを記録します。APIの統計を一括同梱・再配布する構成にはしていません。

## 構成

- `src/HomePage.tsx` / `src/home.css`：トップページ。指定の画像を `public/images/battle-note-hero.png` に配置
- `src/App.tsx`：画面・ナビゲーション・パーティ・バックアップ
- `src/BattleFeatures.tsx` / `src/battle.css`：実計算、相手情報、型比較、採用データの画面
- `src/battle.ts`：Champions計算ライブラリの変換と行動順
- `src/usage.ts`：API検証、日付、キャッシュ、通信失敗時の復旧
- `src/predictions.ts`：既知情報を守る型仮定と行動候補の評価
- `src/data.ts` / `src/generated/battle-catalog.json`：型・カタログ・保存検証
- `src/SpeedPage.tsx` / `src/speed.ts`：全対象のすばやさ比較
- `tests/`：計算、型仮定、矛盾除外、キャッシュ・日付、保存の自動テスト

## 出典・権利表記

- 採用データ：[Pokémon Champions Battle Data](https://championsbattledata.com/api_guide)（非公式）。画面にも指定の帰属表記を掲載
- 計算：[Smogon Damage Calculator](https://github.com/smogon/damage-calc)。バージョンを固定
- 種族・習得技：[Pokémon Showdown](https://github.com/smogon/pokemon-showdown)
- 日本語名称：[PokeAPI](https://github.com/PokeAPI/pokeapi)
- 全358フォームの全身イラスト：[PokeAPI/sprites](https://github.com/PokeAPI/sprites)を基本に、特殊フォーム3点を補完。選択・対戦・パーティ・すばやさ一覧で共通使用。出典と例外は [docs/artwork-sources.md](docs/artwork-sources.md)
- ライセンス文は `public/third-party/` に同梱。アイコンの更新方法と速度データの詳細は [docs/speed-data.md](docs/speed-data.md)

ポケモンの名称・画像等に関する権利は各権利者に帰属します。日本語フォントはGoogle FontsのNoto Sans JPを使用し、接続できない場合はシステムフォントへフォールバックします。
